# 출처 표기

원작자는 Sie예요. 상업적·비상업적 이용 모두 가능하며, LICENSE와 NOTICE의 표기 조건을 유지해 주세요.
화면마다 문구를 넣을 필요는 없어요. 프로젝트 문서와 소개·크레딧·라이선스 화면에 남기면 돼요.

```text
Seria UI by Sie
https://github.com/tsukino-sie/seria-ui
```

소스 파일, 패키지 메타데이터와 빌드 결과에 출처를 포함해요.
ThemeProvider의 루트에는 `data-seria-ui="버전"`, `data-seria-author="Sie"`도 남겨요.
이 정보는 개발자 도구에서 확인할 수 있어요. 외부 서버로 전송하지 않아요.

이 정보는 출처를 확인하는 단서예요. 수정을 통해 제거할 수 있으므로 사용 여부나 원작 여부를 보증하는 인증 수단은 아니에요.
원본 코드와 배포 이력은 이 저장소의 커밋으로 확인해요.
